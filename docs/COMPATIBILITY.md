# 兼容性与验证记录

更新日期：2026-10-08。基线：`Slimefun/Slimefun4@5374034c8`，来源分支 `experimental`。

## 分支 `1.21.11` — Slimefun4 4.9.1

- 编译 API：Paper `1.21.11-R0.1-SNAPSHOT`；最低 Java 21。
- 升级测试后端至 MockBukkit `4.116.3`，迁移包名并修复测试中的旧库存模拟和背包副本引用。
- 修复 `Attribute.MAX_HEALTH`，将头颅物品、机器人移动和电容纹理更新迁移到 Bukkit 公共 PlayerProfile API，移除这些路径对 NMS/authlib 反射的依赖。
- 限制本分支的服务端版本为 1.21.11。保留历史版本枚举供附属插件引用，不代表继续支持旧服务端。
- 分支构建关闭原项目的自动更新及远程指标模块下载，保留原插件名称、包名、物品 ID 和数据键。
- **已验证**：JDK 21 下 `mvn -B -ntp verify`，1,789 项测试，0 失败、0 错误、0 跳过；插件 JAR、源码 JAR 和内嵌 LICENSE 生成成功。
- **未验证**：真实 Paper 的插件启用、玩家进入、背包/电网/物流/机器持续运行、已有存档升级、附属插件兼容。用户要求暂不启动游戏或服务端，等待其提供 Paper 核心。准备中的启动检查已停止在 Paper 下载/补丁阶段，未到服务器就绪状态，不能作为运行验证。

## 分支 `26.2` — Slimefun5

在 1.21.11 的修复基础上继续开发。26.2 API、简繁中文物品本地化及其测试结果在该分支单独记录。未来版本逐版验证并建立独立分支，不承诺未发布版本自动兼容。

## 手动运行验证

`scripts/runtime-smoke.py` 仅在明确传入用户提供的 `--paper-jar` 和 `--accept-eula` 时运行，不自动下载核心。CI 只做编译和单元测试，不启动游戏或服务器。启动探针只能证明其列出的检查；完整游戏行为和附属插件需另外验收。
